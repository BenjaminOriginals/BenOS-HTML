# BenOS-HTML
The HTML edition of BenOS! Performs very well and operates fully on HTML, and can be run in any browser that supports it. Has multiple useful apps, built for everyday productivity. Here is a list of a few:
| App | Function |
|-----|----------|
| BenPen | Making simple art and handwritten notes |
| BenBrowser | A fast, secure, and private browser built for your workflow |
| BenStudio | Native HTML, CSS, and JavaScript editor |
| BenMusic | Ad-free, offline music - no subscription required! |
| App... | More apps will be added in the next commit (do not worry) |

Original build (Sierra) by DedeProGames.
